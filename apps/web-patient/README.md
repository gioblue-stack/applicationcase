# Сайт пациента

Мобильный сайт поверх API пациента (`/api/v1/me/*`). Пациент открывает ссылку в браузере телефона
и добавляет её на рабочий стол — дальше сайт открывается как приложение, без адресной строки.

Экраны: вход по коду (первый вход — с кодом приглашения и согласием), «Сегодня» (дневник, опросники недели,
приём лекарств), PHQ-9 / GAD-7, уточняющий блок, план лечения, план безопасности, вопрос врачу.
Кнопка «Мне сейчас очень плохо» есть на каждом экране и на экране входа.

## Запуск

```bash
./scripts/dev-api.sh                          # API на :8000 и фоновый воркер
npm --prefix apps/web-patient run dev         # сайт на :3001
```

Код входа в режиме разработки не отправляется, а пишется в лог API: `DEV: код входа для …`.
Телефоны демо-пациентов — в `backend/app/seed/demo.py` (`LOGINS`).

## С телефона

1. Телефон и компьютер — в одной Wi-Fi-сети.
2. На телефоне откройте `http://<адрес компьютера>:3001` (адрес на macOS: `ipconfig getifaddr en0`).
3. iPhone (Safari): «Поделиться» → «На экран „Домой“». Android (Chrome): ⋮ → «Добавить на главный экран».

Экран помощи без сети (service worker) работает только на https и на localhost — в пилоте сайт
публикуется по https. В разработке service worker не регистрируется, чтобы не кэшировать старый код.
